# Contributing translations

Thanks for helping! A few rules keep Kron working in every language.

## Keep these exactly as they are

- **Placeholders** in braces: `{user}`, `{count}`, `{server}`, `{inviter.name}`… Move them inside the sentence if your grammar needs it, but never translate or remove them.
- **Discord formatting**: `**bold**`, `*italic*`, `` `code` ``, `> quote`, `### title`, `-# small text`, `<#channel>`, `<@user>`, `<t:…>`.
- **Emojis** at the start of a text (🎫, ✅…).
- **Links** and **commands** (`/role`, `/invites`, `$debug`). Command *names* are translated separately by us: ask on Discord.
- **Brand names**: Kron, Discord, FiveM, Twitch, Kick, Stripe, Crowdin.

## Style

- Short and friendly, like talking to a server owner. Use the informal "you" when your language has one (French uses *tu*).
- Keep the length close to the English text: buttons and menus have little room.
- When a string is unclear, open the context screenshot on Crowdin or ask on Discord.

## Docs (`docs/`)

Translate the text and the `title` / `summary` lines of the front matter. Keep the file name, `category`, `emoji` and `order` as they are.

## Rewards

Rewards count **approved** words only. Keys are sent on our Discord by the team once a month.
