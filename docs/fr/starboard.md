Le **Starboard** republie dans un salon les messages qui reçoivent assez de réactions ⭐ (ou l'emoji de ton choix).

## Réglages

| Réglage | Effet |
|---|---|
| Salon starboard | où les messages sont republiés |
| Emoji | ⭐ par défaut, ou un autre |
| Réactions nécessaires | 3 par défaut |
| Compter l'auteur | si l'auteur peut voter pour son propre message |
| Salons ignorés | salons dont les messages ne vont jamais au starboard |

La carte montre l'auteur, le texte, l'image et un lien vers le message. Le compte se met à jour en direct, et le message quitte le starboard s'il repasse sous le seuil.
