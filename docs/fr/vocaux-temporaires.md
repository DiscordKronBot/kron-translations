Avec les **vocaux temporaires**, un membre qui rejoint le salon **hub** reçoit son propre salon vocal et y est déplacé.

## Mise en place

1. Crée un salon vocal, par exemple `➕ Créer un salon`.
2. Dans le dashboard, choisis-le comme **salon hub**, et si tu veux une **catégorie** pour les nouveaux salons.
3. Règle le **nom** (`{nickname}`, `{username}`, `{count}`) et le nombre de **places**.

## Ce que le membre peut faire

Le créateur gère son salon depuis Discord : le renommer, limiter les places, le verrouiller, déplacer des membres. Le salon est **supprimé dès qu'il est vide**, même si Kron a redémarré entre-temps.
