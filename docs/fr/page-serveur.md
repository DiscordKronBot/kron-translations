La page du serveur est une vitrine publique à partager : nom, icône, bannière, membres en ligne, description, bouton pour rejoindre et formulaires ouverts (whitelist, candidatures…).

### Activer
- Dashboard > **Page du serveur** : active le module, ajoute une description et un lien d’invitation permanent.
- La page est en ligne à `kronbot.xyz/w/<id du serveur>` (lien à copier dans le panel).

### Adresse courte (Pro)
- Avec Pro, choisis une adresse comme `kronbot.xyz/w/kron` (3 à 32 caractères : lettres, chiffres, tirets).
- Chaque adresse est unique. Sans Pro, l’adresse courte ne répond plus, le lien par ID reste actif.

### Options
- **Nombre de membres** : à cacher si tu préfères.
- **Formulaires** : les formulaires activés du module Formulaires sont listés automatiquement.
- **Équipe** : choisis jusqu’à 10 rôles ; leurs membres apparaissent avec leur avatar, sous leur rôle le plus haut.

### Annuaire
- Coche **Afficher mon serveur dans l’annuaire** pour apparaître sur [kronbot.xyz/servers](https://kronbot.xyz/servers), gratuit ou Pro (les serveurs Pro ont une étoile).
- Choisis un type de serveur et jusqu’à 5 tags : on peut chercher et filtrer par nom, tag, type et plan.
