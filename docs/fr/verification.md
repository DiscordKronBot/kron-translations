La **Vérification** fait cliquer les nouveaux membres sur un bouton (ou recopier un code) avant d'accéder au serveur.

## Mise en place

1. Crée un rôle **Vérifié**, sous le rôle de Kron.
2. Rends tes salons visibles seulement pour **Vérifié**, et un salon `✅┆vérification` visible pour @everyone.
3. Dans le dashboard : choisis le salon, le rôle, la méthode, puis **Publier le message**.

## Options

| Option | Effet |
|---|---|
| Méthode | **un clic** sur Vérifier, ou un **code à recopier** (arrête les bots) |
| Âge minimum du compte | refuse les comptes trop récents (souvent des comptes de raid) |
| Rôle retiré | retire un rôle « Non vérifié » donné à l'arrivée par les [rôles automatiques](/docs/roles-auto) |
| Message | le message par défaut, ou le tien avec l'éditeur |
