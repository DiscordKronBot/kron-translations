Le module **Rôles par réaction** publie un message avec des boutons (ou un menu déroulant). Chaque clic donne ou retire un rôle : couleurs de pseudo, notifications, jeux, langues…

## Créer un menu

1. **Nouveau menu** : un modèle est prêt.
2. Choisis le **salon**, l'**affichage** (boutons ou menu) et le **comportement**.
3. Ajoute jusqu'à **25 rôles** : rôle, texte, emoji, couleur du bouton (ou description en mode menu).
4. Personnalise le message avec l'éditeur.
5. Enregistre avec la barre du bas, puis **📤 Publier**. Republie après une modification pour mettre à jour le message.

## Comportements

| Comportement | Effet |
|---|---|
| Basculer | un clic donne le rôle, un autre le retire |
| Unique | un seul rôle de ce menu à la fois (ex. couleur de pseudo) |
| Ajouter seulement | donne le rôle, ne le retire jamais (ex. accepter le règlement) |
| Retirer seulement | retire le rôle, ne le donne jamais |

Le membre reçoit une confirmation visible par lui seul (➕ rôle ajouté, ➖ rôle retiré).

> [!NOTE]
> Le plan gratuit permet 3 menus. Kron refuse l'enregistrement si un rôle est au-dessus du sien.
