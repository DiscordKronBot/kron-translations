The **Starboard** reposts in a channel the messages that get enough ⭐ reactions (or the emoji you pick).

## Settings

| Setting | Effect |
|---|---|
| Starboard channel | where messages are reposted |
| Emoji | ⭐ by default, or another one |
| Reactions needed | 3 by default |
| Count the author | whether the author can star their own message |
| Ignored channels | channels whose messages never go to the starboard |

The card shows the author, the text, the image and a link to the message. The count updates live, and the message leaves the starboard if it drops under the threshold.
