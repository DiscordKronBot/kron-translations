The **Reaction roles** module posts a message with buttons (or a dropdown menu). Each click gives or removes a role: name colors, notifications, games, languages…

## Create a menu

1. **New menu**: a template is ready.
2. Pick the **channel**, the **display** (buttons or menu) and the **behavior**.
3. Add up to **25 roles**: role, text, emoji, button color (or description in menu mode).
4. Customize the message with the editor.
5. Save with the bottom bar, then **📤 Publish**. Publish again after a change to update the message.

## Behaviors

| Behavior | Effect |
|---|---|
| Toggle | one click gives the role, another removes it |
| Unique | only one role of this menu at a time (e.g. name color) |
| Add only | gives the role, never removes it (e.g. accept the rules) |
| Remove only | removes the role, never gives it |

The member gets a confirmation only they can see (➕ role added, ➖ role removed).

> [!NOTE]
> The Free plan allows 3 menus. Kron refuses to save if a role is above its own.
