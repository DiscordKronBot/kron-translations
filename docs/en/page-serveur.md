The server page is a public showcase to share: name, icon, banner, members online, description, a join button and open forms (whitelist, applications…).

### Turn it on
- Dashboard > **Server page**: turn the module on, add a description and a permanent invite link.
- The page is live at `kronbot.xyz/w/<server id>` (copy the link from the panel).

### Short address (Pro)
- With Pro, pick an address like `kronbot.xyz/w/kron` (3 to 32 characters: letters, digits, dashes).
- Each address is unique. Without Pro the short address stops answering; the ID link keeps working.

### Options
- **Member count**: hide it if you prefer.
- **Forms**: enabled forms from the Forms module are listed automatically.
- **Team**: pick up to 10 roles; their members show with their avatar, under their highest role.

### Directory
- Tick **Show my server in the directory** to appear on [kronbot.xyz/servers](https://kronbot.xyz/servers), free or Pro (Pro servers get a star).
- Pick a server type and up to 5 tags: people can search and filter by name, tag, type and plan.
